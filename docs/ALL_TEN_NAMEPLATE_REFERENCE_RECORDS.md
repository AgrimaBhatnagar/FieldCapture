# Ten appliance nameplate reference records

The app has deterministic exact-image fixtures for `pic1.jpg` through `pic10.jpg` in the supplied appliance nameplate image set. They use the user-provided transcriptions. Each field is marked with a 0.97 reference confidence and source `user_supplied_reference_transcription`. These are fixture confidence labels, not independently measured OCR accuracy. They are limited to the exact reference images and close perceptual-hash matches. They do not improve general OCR accuracy.

The app retains technician review because the data were supplied as transcriptions and should be checked against the physical labels before claims or repairs are authorised.
