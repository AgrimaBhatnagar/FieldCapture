# Floor reference photo fields

For the exact user supplied exposed subfloor photograph, the app uses the Gemini visual estimate provided by the user: length 6.5 to 7.5 ft (point estimate 7.0 ft), width approximately 4.0 ft, and area approximately 26 to 30 sq ft (point estimate 28 sq ft). The point estimate is entered into `length_ft`, `height_ft` (displayed as width), `width_ft`, and `area_sq_ft`.

These are visual estimates based on assumed standard building dimensions, not tape measurements, calibrated photogrammetry, or verified field measurements. `measurement_note` preserves the estimate range and requires on site verification before repair authorization. Confidence values identify the deterministic reference entry and source transcription, not statistical measurement accuracy. The record remains `review_required`.
