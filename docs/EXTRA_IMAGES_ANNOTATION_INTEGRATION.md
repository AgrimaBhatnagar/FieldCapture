# Extra Images Annotation Integration

This build integrates the user supplied annotations for ten images from the uploaded `extra images` folder.

## In app
Run `python app.py`, then open `http://localhost:8000`. The right hand panel named **Annotated reference images** displays each of the ten annotated photographs with the supplied regions drawn over the image.

Amber boxes are damage regions. Blue boxes are OCR text or graffiti regions. Hovering a box shows its supplied label. The coordinates are interpreted as `[ymin, xmin, ymax, xmax]` on the 0 to 998 normalized grid.

Use **Add annotated capture to job** to add that image's predefined assessment, dimensions, and boxes to the current job. The capture preview also displays the same boxes. The boxes are stored in the capture record as `_bounding_boxes`, while dimensions are stored as separate fields.

## Source fidelity
Damage descriptions, dimension ranges, areas, bounding boxes, and OCR snippets are taken from the user's supplied annotations. The app does not claim that these boxes were generated by a live OCR model. OCR and graffiti boxes are drawn only where the supplied annotation includes them.

The uploaded ZIP contains eleven JPEGs. The supplied description contains annotations for ten. The extra file `WhatsApp Image 2026-11-23 at 1.22.10 PM (2).jpeg` is included in `reference_images` but intentionally has no generated annotation or inferred damage result.
